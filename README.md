# AURION

**Ouvrir l’application :** https://bienvenuesurleJ.github.io/aurion-desk/

Un seul fichier HTML, sans installation : [docs/index.html](docs/index.html). La session papier se lance dans le navigateur.

Desk de trading privé. Compte papier, flux accéléré, analyse calculée en direct.

Le robot ne parle pas à un exchange. Il lit un carnet simulé, calcule EMA, RSI, ATR et MACD, dimensionne le risque, pose stops et cibles, puis tient le livre. C’est le desk de démonstration — le branchement réel viendra quand la salle sera prête.

## Ce que le desk fait

- Six marchés : BTC, ETH, SOL, BNB, AVAX, or
- Quatre doctrines : Pulse, Reversion, Rupture, Ancre
- Risque par trade, trois expositions maximum, coupe-circuit à −1,50 %
- Carnet, tape, courbe de capital, journal

Ouvrir l’aperçu. Le robot est déjà armé.
