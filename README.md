# AURION

**Ouvrir le robot :** https://bienvenuesurlej.github.io/aurion-desk/

Desk papier autonome. Il lit six marchés, choisit long ou short, pose le stop et la cible, puis tient le livre. Pas de menu de téléphone : l’application est le robot.

Le moteur tourne dans le navigateur, sans installation.
